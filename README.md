# SKYBLOOM VOXEL

天空の島々をジャンプ、風ショット、光グラップルで巡るボクセル・パルクールゲーム。

**遊ぶ:** https://puniu3.github.io/skybloom-voxel/

インストールやログインは不要です。WebGL対応ブラウザで開いてください。

## 操作

- PC: WASD / 矢印で移動、マウスで視点操作、Spaceでジャンプ、左クリックで風ショット、右クリック / Eでグラップル。
- タッチ端末: 方向ボタンで移動、画面をドラッグして視点操作、画面下のボタンで各アクション。横向きがおすすめです。
- Rでチェックポイントに復帰、Fで空中散歩モードを切り替え。
- 「操作・設定」で影・パーティクル・視点感度を調整できます。

## 配信

ゲーム本体は `public/index.html` です。Three.js r128、Tailwind CSS 3.4.17、Google Fontsを外部配信元から読み込みます。

GitHub Pagesは `main` ブランチの `public/` をGitHub Actionsで公開します。
